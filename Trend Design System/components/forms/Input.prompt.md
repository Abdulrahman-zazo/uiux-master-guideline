Single-line text entry — a soft grey fill with no resting border; focus reveals a purple 1px ring.

```jsx
<Input placeholder="Full name" />
<Input iconStart="mail" type="email" placeholder="you@example.com" />
<Input suffix="SAR" inputMode="decimal" placeholder="0.00" />
<Input invalid placeholder="Invalid card" />
```

Radius is always 12px on inputs — pills are for buttons only (SearchField is the one exception).
