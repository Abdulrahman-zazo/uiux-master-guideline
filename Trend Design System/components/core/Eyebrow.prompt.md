The wide-tracked uppercase category marker that sits 8–12px above a heading — a signature Trend move.

```jsx
<Eyebrow>New this week</Eyebrow>
<Eyebrow tone="brand">Editor's pick</Eyebrow>
```

Always 12px / 500 / +0.05em / uppercase. Arabic copy skips the uppercase transform (no case in Arabic) but keeps the tracking.
