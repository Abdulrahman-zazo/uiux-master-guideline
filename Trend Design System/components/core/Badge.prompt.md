A capsule status label — order states, stock states, promo flags. Always pill-shaped, always 12px type.

```jsx
<Badge tone="brand">-30%</Badge>
<Badge tone="success" dot>Delivered</Badge>
<Badge tone="warning" icon="clock">Pending</Badge>
<Badge tone="outline">Free shipping</Badge>
```

Badges label state. For user-selectable filters use `Tag` instead.
