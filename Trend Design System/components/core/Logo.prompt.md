The Trend wordmark, served from the supplied SVG — use this instead of setting the brand name in type.

```jsx
<Logo height={28} assetBase="../../assets/" />
<Logo variant="mark" height={32} assetBase="../../assets/" />
<Logo theme="dark" height={24} assetBase="../../assets/" />
```

On any surface darker than `--neutral-600`, pass `theme="dark"`.
