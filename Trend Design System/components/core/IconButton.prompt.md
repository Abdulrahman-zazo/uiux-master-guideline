A square-footprint icon-only control — wishlist hearts, carousel arrows, close buttons, toolbar actions.

```jsx
<IconButton icon="heart" label="Save to wishlist" />
<IconButton icon="chevron-left" label="Previous" size="lg" />
<IconButton icon="x" label="Close" variant="ghost" />
<IconButton icon="share-2" label="Share" variant="inverse" />
```

`label` is mandatory. `variant="inverse"` is the translucent control that sits on product imagery.
